## 方法

- 資料の信頼順（精査メモ → リポジトリのレポート2本 → 収集メモ・バッチJSON → 現在の本番データ）で公表値の組を決めた。
- 千葉は精査後にモルの監査対応（2026-11-16）が入っており、多くの駅で現行値が「ちば観光ナビ（千葉県公式観光サイト、観光協会扱い）」の公表値に差し替わっている。監査対応スクリプト（apply-chiba-audit-fixes.py）に残っていた ちば観光ナビ のURLと、同サイトの道の駅特集ページからのリンクで各駅ページを2026-11-19に直接確認し、現行値と一致する駅はその出典の公表セット（身障者用を含む）を転記した。取得は間隔を空けて行い、429は発生しなかった。
- 連絡会の原文表記が資料に残っていない駅（とみうら・くりもと・発酵の里こうざき）は、連絡会の当駅ページを2026-11-19に直接開いて原文表記を確認した。
- 旧方式（2026-11-16決定）で「普通車N（身障者用M）は N−M と読む」「身障者用・軽・EVを普通から差し引く」処理が残っていた駅は、出典の公表形の転記に戻した（やちよ、みのりの郷東金）。

## 判断・チェックが要りそうな駅

1. **やちよ（大型の扱い）** — 連絡会の公表は「大型：現在はリニューアル工事に伴い使用できません 0台」。公表値の転記としては 0台 とも読めるが、工事中（2026年12月28日まで）の一時状態を恒常値にしない従来判断（収集・精査とも null）を踏襲して null とした。0台で転記するかはモル・所有者の判断が要る。
2. **たけゆらの里おおたき（総数・バス専用・表記）** — 駅公式の公表内訳は「102台（大型 2台、バス専用 3台、普通車89台、軽自動車６台、身障者優先２台）」。総数102は公式の公表総数として転記した。大型は公式の「大型2＋バス専用3」と連絡会の公表値5が一致するため5としたが、バス専用を大型に含める読みの最終確認が要る。身障者用の原文表記は「身障者優先」で、そのまま転記した（basis に原文を残した）。
3. **多古（バス専用）** — 大型15は、第2駐車場の大型12に第1駐車場のバス専用3を加えた値で、連絡会の公表値15とも一致する（精査メモで確認済みの読み）。たけゆらと同じく、バス専用を大型に含める扱いの確認が要る。
4. **三芳村（身障者用が未確認）** — 現行の普通70・大型8は監査で ちば観光ナビ（観光協会）の公表値に差し替えたもの。同サイトは身障者用を公表していない。連絡会は「普通車76（身障者用3）」と公表するが、普通車の数字自体が70と矛盾するため、矛盾する場合は上位出典だけを出すルールに従い身障者用は併記せず null とした。連絡会の3台をどう扱うか判断が要る。
5. **富楽里とみやま（身障者用の範囲）** — 普通203・大型6は所有者決定（2026-11-16）で高速側（PA）と南側（高速バス利用者専用）を除いた公式ベースの値。身障者用は同じ範囲（一般道側）の公表値1台だけを転記し、高速側の身障者用2台は除外範囲のため含めていない。この切り分けでよいか確認が要る。
6. **身障者用の原文表記のばらつき** — 出典の原文表記が駅ごとに異なる（『身体障害者用』ふれあいパーク・きみつ、『障害者用』あずの里いちはら・むつざわ・水の郷さわら、『身障者優先』たけゆらの里おおたき、『障がい者用』きょなん）。いずれも各駅の basis に原文表記を残した。表示側の項目名は「身障者用」で統一される前提で転記しているが、扱いをそろえるなら確認が要る。
