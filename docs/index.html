道の駅ポチ

ドライブの休憩に立ち寄る道の駅について、駐車場の台数やEV充電・温泉などの設備を、公式の案内をもとにまとめました。現在は埼玉県の21駅を掲載しています。料金・営業時間・休館日などは変更される場合があります。お出かけ前に、必ず各施設の公式ページで最新の情報をご確認ください。

このサイトの情報について

掲載している情報は、国土交通省の道の駅登録一覧・全国道の駅連絡会・各駅の公式サイトなどの一次情報で確認したものだけです。各駅のページに出典と確認日を明記し、確認できなかった項目は載せていません。料金・営業時間・休館日などは変更される場合があります。お出かけ前に、必ず各施設の公式ページで最新の情報をご確認ください。

道の駅ポチは、道の駅の情報を各駅の公式サイトや道の駅連絡会などの一次情報で確認してまとめています。
