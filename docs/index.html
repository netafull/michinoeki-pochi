道の駅ポチ

道の駅の駐車場・設備を、まとめて探す

ドライブの休憩に立ち寄る道の駅について、駐車場の台数やEV充電・温泉などの設備をまとめています。現在、掲載データの精査を行っており、精査が終わった都道府県から順次公開します。

道の駅ポチは、道の駅の情報を各駅の公式サイトや道の駅連絡会などの一次情報で確認してまとめています。

当サイトは各道の駅・国土交通省・全国道の駅連絡会とは関係のない非公式サイトです。営業時間・駐車台数・設備は確認日時点のものです。最新の情報は各駅の公式サイトでご確認ください。
